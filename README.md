# Bloom — AI Floral Design Platform (KAD)

Liquid glass morphism landing page for Bloom AI.

## Deploying to GitHub Pages

This project is pre-configured for seamless deployment to **GitHub Pages**:

### Option 1: Automatic Deployment via GitHub Actions (Recommended)
1. Push this repository to GitHub.
2. Go to your repository **Settings** -> **Pages**.
3. Under **Build and deployment** -> **Source**, select **GitHub Actions**.
4. Every push to `main` or `master` will automatically build and publish the site!

### Option 2: Manual Build
1. Run `npm install`
2. Run `npm run build`
3. The production-ready static files are generated in the `dist/` directory with relative asset paths.
